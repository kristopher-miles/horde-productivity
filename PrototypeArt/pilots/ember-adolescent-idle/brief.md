# Ember Adolescent Idle Brief

Four-frame transparent idle loop for Ember's Adolescent stage, derived from the approved Baby seed as the next member of one replaceable dragon family.

| Property | Requirement |
| --- | --- |
| Runtime frame | `108x90` RGBA PNG, rendered 1:1 |
| Order | `ember-adolescent-idle-01.png` through `-04.png` |
| Timing | `180 ms` each, looping |
| Motion | planted breath, slight wing follow-through, blink, return |
| Anchor | bottom-center `(0.5, 0.0)`; common visible baseline |
| Scene placement | anchor at native scene point `(184, 40)` |
| Runtime display | `108x90`, nearest-neighbor |
| Reduce Motion | frame 01 |

Preserve Ember's left-facing three-quarter identity, five recolorable orange body tones, cream horns/belly, dark outline, eye colors, four grounded limbs, wings, dorsal spikes, and curled tail. Evolve the silhouette beyond Baby with a longer snout and limbs, larger swept wings, and taller horns while remaining visibly young. One complete ordered strip is generated; frames are never generated separately.

At 1× in the `320x180` scene, Adolescent must read as distinctly taller and longer than Baby without baseline jump, blur, detached effects, scenery, text, or frame-to-frame scale drift.
