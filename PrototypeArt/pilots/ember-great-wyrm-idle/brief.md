# Ember Great Wyrm Idle Brief

Four-frame transparent idle loop for Ember's final Great Wyrm stage, derived from the approved Elder frame.

| Property | Requirement |
| --- | --- |
| Runtime frame | `144x120` RGBA PNG, rendered 1:1 |
| Order | `ember-great-wyrm-idle-01.png` through `-04.png` |
| Timing | `180 ms` each, looping |
| Motion | immense planted breath, restrained wing settle, slow blink, return |
| Anchor | bottom-center `(0.5, 0.0)`; common visible baseline |
| Scene placement | anchor at native scene point `(184, 40)` |
| Runtime display | `144x120`, nearest-neighbor |
| Reduce Motion | frame 01 |

Preserve Ember identity and all recolorable/detail tones. Great Wyrm is the largest, ancient and fortress-like: longest horns, crown of dorsal spines, vast folded wings, barrel chest, powerful forelimbs, and a sweeping heavy tail. The exact visible label is **Great Wyrm**.

At 1×, Great Wyrm must dominate more of the `320x180` composition than Elder while staying readable and fully contained, with a stable bottom-center loop.
