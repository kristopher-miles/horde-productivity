# Room Hazard Appears Brief

## Purpose

Create a bounded four-frame environmental concern cue that composes over the approved room without naming a specific generated story or implying catastrophe.

| Property | Requirement |
| --- | --- |
| Asset/cue | `room` / `hazard-appears` |
| Runtime frame | `320x180` transparent RGBA PNG |
| Frames/timing | 4 frames, `120 ms` each, one-shot |
| Order | `room-hazard-appears-01.png` through `-04.png` |
| Registration | scene origin `(0, 0)`; integer placement |
| Reduce Motion | frame 04, restrained committed hazard state |

Motion beats: a faint local amber-violet light shift near the central hearth masonry → one small crack/draft line appears → its edges clarify with a slight dust curl → settle to a quiet static crack and dim local accent. Keep the effect inside a compact central area and behind character faces. No global dim, camera shake, combat, collapse, fire burst, lightning, text, or room replacement.
