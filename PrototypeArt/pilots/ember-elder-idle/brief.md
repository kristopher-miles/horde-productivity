# Ember Elder Idle Brief

Four-frame transparent idle loop for Ember's Elder stage, derived from the approved Adult frame.

| Property | Requirement |
| --- | --- |
| Runtime frame | `132x110` RGBA PNG, rendered 1:1 |
| Order | `ember-elder-idle-01.png` through `-04.png` |
| Timing | `180 ms` each, looping |
| Motion | slow planted breath, wing settle, deliberate blink, return |
| Anchor | bottom-center `(0.5, 0.0)`; common visible baseline |
| Scene placement | anchor at native scene point `(184, 40)` |
| Runtime display | `132x110`, nearest-neighbor |
| Reduce Motion | frame 01 |

Preserve the Ember family and recolorable tones. Elder grows deeper-chested with longer crown horns, heavier wing bones, a ridged brow, and a commanding low stance. Age reads through silhouette, not accessories or a human beard.

At 1×, Elder must exceed Adult in silhouette, scale, and authority while retaining a stable loop and clear scene fit.
