# Room Recovery Glow Brief

## Purpose

Create the chosen two-frame restrained recovery transition. It must be warmer and steadier than normal, able to persist as frame 02 under Reduce Motion, and remain clearly calmer than celebration.

| Property | Requirement |
| --- | --- |
| Asset/cue | `room` / `recovery-glow` |
| Runtime frame | `320x180` transparent RGBA PNG |
| Frames/timing | 2 frames, `180 ms` each, one-shot |
| Order | `room-recovery-glow-01.png`, `room-recovery-glow-02.png` |
| Registration | scene origin `(0, 0)`; integer placement |
| Reduce Motion | frame 02, persistent steady treatment |

Frame 01 is a faint low warm-cream/teal reflected-light cluster. Frame 02 opens slightly into a stable soft arch or floor-edge reflection behind the characters. No washout, bloom, particles, rays, sparkle, text, characters, or room replacement.
