# Kobold Adult Idle Brief

## Purpose

Promote the approved canonical kobold master to the reusable Adult age model and runtime idle loop for NPC-03 without redrawing or recoloring it.

| Property | Requirement |
| --- | --- |
| Asset/cue | `kobold-adult` / `idle` |
| Runtime frame | `48x64` transparent RGBA PNG |
| Frame count | exactly 4 |
| Timing | `200 ms` per frame, looping |
| Registration | two-pixel inset; bottom-center `(0.5, 0)`; planted baseline at native y `62` |
| Occupied height | `60 px`, strictly taller than Baby and Kid |
| Scene placement | representative bottom-center at `(52, 40)` |
| Facing | three-quarter view facing right |
| Reduce Motion | frame 01 |

## Model identity and invariants

- Byte-preserve the approved `kobold-master-idle` silhouettes and animation while renaming the delivery contract to Adult.
- Compact friendly adult kobold with short snout, cream eye, swept horns, attached curled tail, two arms, two planted feet, and practical neutral tunic.
- Stone-brown/orange skin and neutral gray/cream tunic remain visibly palette-separated for later authored recoloring.
- No new generation, redraw, accessory, color change, or motion change.
