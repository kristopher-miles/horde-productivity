# Ember Concern Pilot Brief

## Deliverable

A four-frame transparent one-shot concern reaction using the approved Ember identity seed from the idle pilot.

| Property | Requirement |
| --- | --- |
| Runtime frame | `96x80` RGBA PNG |
| Frame count | exactly 4 |
| Order | `ember-concern-01.png` through `ember-concern-04.png` |
| Timing | `140 ms` per frame, one-shot |
| Registration | same two-pixel inset and bottom-center `y=78` visible baseline as idle |
| Scene placement | bottom-center anchor at integer point `(184, 40)` in bottom-left scene coordinates |
| Facing | three-quarter view facing left |
| Background | genuine transparency; no scenery, labels, shadows, borders, or detached effects |

## Motion beats

1. Exact approved idle seed.
2. Head lowers slightly and the open eye widens; body remains planted.
3. Clear concern peak: body draws inward, wings tuck, tail curls tighter, eye remains readable; no melodrama or tears.
4. Settle into a readable concerned hold, not a return to neutral.

Pass when concern reads before accompanying prose at 1x, without silhouette, scale, facing, or anchor drift.
