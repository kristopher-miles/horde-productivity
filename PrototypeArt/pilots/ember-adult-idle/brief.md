# Ember Adult Idle Brief

Four-frame transparent idle loop for Ember's Adult stage, derived from the approved Adolescent frame.

| Property | Requirement |
| --- | --- |
| Runtime frame | `120x100` RGBA PNG, rendered 1:1 |
| Order | `ember-adult-idle-01.png` through `-04.png` |
| Timing | `180 ms` each, looping |
| Motion | planted breath, wing follow-through, blink, return |
| Anchor | bottom-center `(0.5, 0.0)`; common visible baseline |
| Scene placement | anchor at native scene point `(184, 40)` |
| Runtime display | `120x100`, nearest-neighbor |
| Reduce Motion | frame 01 |

Preserve family identity and recolorable body tones. Adult gains a broad chest, longer muzzle and tail, full wings, and pronounced horns while remaining quadrupedal and left-facing. Generate the complete ordered strip together.

At 1×, Adult must exceed Adolescent in silhouette mass and scene presence, loop without anchor jump, and remain inside the native scene staging area.
