# Room Resource Change Brief

## Purpose

Create a six-frame material-change overlay that can accompany positive or recoverable prose by drawing attention to reusable room resources rather than generic celebration.

| Property | Requirement |
| --- | --- |
| Asset/cue | `room` / `resource-change` |
| Runtime frame | `320x180` transparent RGBA PNG |
| Frames/timing | 6 frames, `90 ms` each, one-shot |
| Order | `room-resource-change-01.png` through `-06.png` |
| Registration | scene origin `(0, 0)`; integer placement |
| Reduce Motion | frame 04, the most informative material-change still |

Motion beats: faint warm focus → one compact repaired-stone seam and stocked-food silhouette appear → details clarify → informative peak → restrained fade → clean near-empty settle. Effects remain local and must disappear cleanly before idle. No coins, confetti, text, floating UI icons, global glow, characters, or full-room replacement.
