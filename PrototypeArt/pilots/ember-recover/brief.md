# Ember Recover Brief

## Purpose

Create a restrained five-frame one-shot in which Ember relaxes from bounded concern into a steady, hopeful pose before returning to idle.

## Canonical input

Use `PrototypeArt/pilots/ember-idle/normalized/ember-seed-v3-01.png` as Ember's approved identity seed and exact frame 01.

| Property | Requirement |
| --- | --- |
| Asset/cue | `ember` / `recover` |
| Runtime frame | `96x80` transparent RGBA PNG |
| Frame count | exactly 5 |
| Order | `ember-recover-01.png` through `ember-recover-05.png` |
| Timing | `110 ms` per frame, one-shot |
| Registration | two-pixel inset; bottom-center; common visible baseline |
| Scene placement | bottom-center at integer `(184, 40)` |
| Facing | three-quarter view facing left |
| Reduce Motion | frame 04, the clearest steady hopeful pose |

## Identity invariants

Preserve the seed's horn count and shape, round snout, cream belly, ember-orange body, compact wings, short legs, curled tail, dark-violet outline, face, proportions, palette family, facing, and apparent scale.

## Motion beats

1. Exact approved neutral seed, serving as the committed starting pose.
2. Head lowers slightly and wings draw inward to acknowledge tension.
3. Shoulders and wings begin to open; eye softens; feet remain planted.
4. Clear recovery peak: open posture, lifted attentive head, calm hopeful expression.
5. Settle close to neutral for a clean handoff to idle.

No particles, glow, text, scenery, detached effects, camera motion, extra characters, tears, panic, combat pose, airborne jump, or exaggerated squash/stretch.
