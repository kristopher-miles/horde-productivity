# Kobold Master Idle Brief

## Purpose

Approve one plain canonical kobold body plan and create its four-frame idle loop. This master must support Pip, Moss, and Rill through controlled palette and attached-accessory changes without redrawing the motion family.

| Property | Requirement |
| --- | --- |
| Asset/cue | `kobold-master` / `idle` |
| Runtime frame | `48x64` transparent RGBA PNG |
| Frame count | exactly 4 |
| Order | `kobold-master-idle-01.png` through `kobold-master-idle-04.png` |
| Timing | `200 ms` per frame, looping |
| Registration | two-pixel inset; bottom-center; common planted foot baseline |
| Scene placement | representative bottom-center at `(52, 40)` |
| Facing | three-quarter view facing right |
| Reduce Motion | frame 01 |

## Canonical identity and invariants

- Compact friendly underground resident with a short snout, one visible cream eye, small swept horns, long attached tail, two arms, two planted feet, and practical neutral tunic.
- Plain stone-brown/cream base palette with dark-violet outline, deliberately neutral enough for teal, moss, and slate variants.
- Stable snout, eye, horn count, tail, hands, feet, body proportions, facing, scale, and baseline in every frame.
- No role-specific accessory in the master.

## Motion beats

1. Approved neutral seed.
2. Small inhale; torso rises minimally while feet stay planted.
3. One readable blink with tiny tail follow-through.
4. Return close to neutral for a seamless loop.

No weapon, readable list, mushroom, tool, lantern, particles, shadow patch, scenery, text, border, or detached effect.
