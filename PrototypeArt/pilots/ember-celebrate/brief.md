# Ember Celebrate Acceptance Brief

## Purpose

Create the repository skill's fresh-context acceptance asset: a clear, restrained positive reaction for goal completion. This is replaceable prototype art and must not be integrated into the app during the acceptance run.

## Canonical input

Use `PrototypeArt/pilots/ember-idle/normalized/ember-seed-v3-01.png` as Ember's approved identity seed and exact first frame.

## Deliverable

| Property | Requirement |
| --- | --- |
| Asset/cue | `ember` / `celebrate` |
| Runtime frame | `96x80` RGBA PNG |
| Frame count | exactly 6 |
| Order | `ember-celebrate-01.png` through `ember-celebrate-06.png` |
| Timing | `90 ms` per frame, one-shot |
| Registration | two-pixel inset; bottom-center; shared visible baseline |
| Scene placement | bottom-center anchor at integer point `(184, 40)` |
| Facing | three-quarter view facing left |
| Background | genuine transparency after deterministic cleanup |
| Reduce Motion | frame 04, the clearest positive pose |

## Identity invariants

Preserve the seed's horn count and shape, round snout, cream belly, orange ember-scaled body, compact wings, short legs, curled tail, dark-violet outline, face, proportions, palette family, facing, and apparent scale.

## Motion beats

1. Exact approved neutral seed.
2. Anticipation: small crouch and brighter/wider eye; feet remain planted.
3. Lift: head and compact wings rise, body opens, tail follows.
4. Celebration peak: delighted expression and clearest upward silhouette; energetic but not airborne.
5. Settle: head and wings lower with a small tail follow-through.
6. Return close to neutral so runtime can hand back to idle without a visual pop.

No particles, confetti, text, scenery, detached effects, camera motion, extra characters, tears, combat pose, or exaggerated squash/stretch.

## Acceptance

Pass deterministic validation and Pixelorama source checks, then visually confirm at 1x that the six frames read neutral → anticipation → lift → delighted peak → settle → near-neutral before accompanying prose is read. Preserve identity, baseline, size, and facing throughout. Save the brief-derived manifest, exact prompt, generation attempt(s), normalized frames, `.pxo`, contact sheet, GIF preview, decision, and evidence entry.
