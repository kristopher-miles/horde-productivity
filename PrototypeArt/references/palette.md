# Candidate 32-Color Prototype Palette

This is a deliberately broad prototype palette sampled and regularized from the current dungeon composition. It preserves character identity colors that a frequency-only quantizer discarded. Transparency is outside the 32 visible colors.

| Family | Hex colors |
| --- | --- |
| Outline and violet stone | `#05040B` `#0E0B19` `#17152A` `#24223A` `#34334C` `#4A465E` |
| Wood and earth | `#51240F` `#753615` `#A6531F` `#D07A2F` `#F0B44B` |
| Warm cream | `#D0B58A` `#FFE08A` |
| Ember orange | `#6B190A` `#A32B0A` `#D94D08` `#F2760D` `#FF9E25` `#FFD062` |
| Teal | `#0B3C42` `#15565A` `#28777A` `#45A19A` |
| Moss | `#2C4217` `#4B6522` `#6F8B2D` `#98A83C` |
| Blue | `#153C55` `#245D77` `#3B8199` |
| Neutral leather/stone | `#6A5546` `#9A7A5B` |

The palette is a cleanup target, not a demand that ImageGen emit exact indexed color. P3 must report off-palette pixels before manual correction.
